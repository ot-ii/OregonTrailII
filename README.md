# otii_c

A C port of Oregon Trail II over the course of 4+ years, made custom tooling
to double check the C++ code was the same, found issues along the way, and
fixed. Auto pilot has run over 4000 games now, and appears to be stable!
- It behaves the same: the same RNG stream, stuff like that
- It builds for 32- and 64-bit as `otii32.exe` and `otii64.exe`.

I have many versions of Oregon Trail II now, and they all work, except the demo version.

## Building
Needs c++ build tools, that's it. Just run nmake, check the makefile for optional stuff.
